# medicube_marketing

에이피알(APR) 메디큐브 마케팅 직무 지원을 준비하며 진행한 **기업분석·시장 리서치** 기록입니다.
네이버 데이터랩 검색 지수(국내)와 글로벌 1차 출처 검증, 구글 트렌드 실측 CSV 13종을 근거로, 지금 메디큐브의 수요가 어디로 옮겨갔는지와 지원 전략을 정리했습니다.

이 저장소는 에이피알 지원서 제출용 **비공개 저장소**이며, 공식 제품 사진을 넣은 시안 PNG·PSD와 숏폼 조립 초안도 `private_submission/`(2030·5060 65개 파일)에 함께 담았습니다. 다만 제품 이미지의 재사용 허락은 확인되지 않았으므로 이 파일들은 **광고 집행·공개 웹·SNS·유튜브 게시에 쓰지 않습니다**. 고객용 시안에는 `승인 전 콘셉트`를 표기하고, 제품 변경·출시·편성 확정으로 읽히는 문구는 넣지 않았습니다. 14쪽 포트폴리오는 `reports/메디큐브_콘텐츠마케팅_포트폴리오.pdf`(MD 동시 생성)입니다.

## 경쟁군을 이 4개로 고른 이유 (보고서 `00-B` · 사전근거 `1.10 ⑦`)

- **범위**: 비교는 **K-뷰티 스킨케어 직접 경쟁군 안의 상대 점유**로 한정했습니다. 아모레퍼시픽(라네즈) 같은 1세대 대형 CeraVe·라 로슈포제·더 오디너리 같은 현지 매스는 체급·가격대·유통이 다른 축이라 같은 눈금에 세우지 않았습니다.
- **한도**: 구글 트렌드는 한 요청에 5개(메디큐브+4)까지라, ① 카테고리 일치(색조 롬앤·바디 일리윤·1세대 대형 라네즈/이니스프리 제외) ② 2026-11-19 실측 순위 근접도 ③ BIODANCE 공통 앵커 + COSRX 역성장 대조군으로 추렸습니다.
- **플랫폼 위상**: 영국은 뷰티 소비의 45.5%가 온라인·그 온라인의 35.1%가 아마존 UK(2023 MAT)이고 틱톡샵이 9.8%(2025 YTD·2위)입니다. 일본은 화장품 이커머스 비중이 10% 미만이고 그 온라인의 1위가 Qoo10(25~30% 이상)입니다 — 그래서 Qoo10 #38·아마존 JP 0개는 '일본 부진'이 아니라 채널 구조의 값입니다.

## 국내 경쟁군을 이 5개로 고른 이유 (국내 보고서 `00-B`)

- **근거는 매대 실측입니다** — **2026-11-20 04:08 KST 실시간 랭킹 Top100(1차 실측)** 에서 **에스트라 5개(1·12·37·46·73)** · **메디힐 5개(5·15·48·58·98)** · **넘버즈인 4개(30·39·56·57)** · **토리든 1개(9)** · 메디큐브 3개(26·61·81). 11-19 크롤 캐시(에스트라 1·11·48·51·85 · 메디힐 7·24·53·57·74 · 넘버즈인 31·44·55·64 · 토리든 14 · 메디큐브 28·86)와 비교하면 **경쟁군 5개의 개수는 그대로**이고 순위만 움직였습니다(보고서 `00-B` 표 0-3·0-3-A).
- **축이 겹치지 않게** 골랐습니다 — 에스트라=크림 1위(2025 어워즈) · 메디힐=패드 1위 · 토리든=에센스·마스크팩 1위 · 넘버즈인=로션 1위 · 메디큐브=디바이스 1~3위.

## Task 2 — 타깃 가설과 검증 설계

현재 [타깃·가설 보고서](reports/메디큐브_국내_타깃가설_마케팅전략.md)는 v2.9 MD·PDF 동기화본입니다. 서로 다른 분모의 검색·클릭 차이를 문제나 퍼널 병목으로 해석한 문장을 교정했고, 미니는 기존 전략의 검토 대상, 글로우는 우선 검증 후보로 두었습니다. 글로우 리뷰 원문은 공식몰 217건·글로우픽 15건을 수집하고 표시 건수와 대조했습니다. [수집 기록](analysis/task2/glow_review_collection.md)에 범위를 기록했습니다. 232행의 1차 수동 코딩을 완료하고 [2030 전략 연결안](reports/메디큐브_글로우_리뷰분석_2030전략연결.md)에 메시지·랜딩·브랜드 광고 형식 조사 근거(10-B)·**30초 3샷 상황극 원안 콘티 v1.2와 29.8초 제작 편집안(11장)**·**5단계 경쟁사 표현 중복 검수표(12장)**·향후 실험 설계 예시를 정리했습니다. 출시 후 동일 기간 검색과 공식 제품 정보 대조를 통해 조건부 채택했으며, 현행 전략·콘티·AI 제작 난이도 절감 방식은 연결안 9–12장에 있습니다. 공식몰 키워드 O01–O12와 리뷰 주제 R01–R06, 피크 주 경쟁 사례 B01–B03의 추적표 및 원소재 표현 중복 검수를 마쳤습니다. 독립 의미 재코딩은 남아 있습니다. 광고 계정과 방문·주문 로그가 없어 실제 효과 실험은 현재 수행할 수 없으며, 포트폴리오는 공개 근거 검증과 콘텐츠 제작·표현 검수까지 다룹니다. 공식몰 **미니** 리뷰 200건의 CSV 태그를 재집계해 휴대 115건(57.5%), 입문 101건(50.5%)으로 바로잡았습니다. 200건의 추출 기준과 태그 적합성은 미확인입니다. 글로우픽 **미니·미니 플러스** 82건 중 74건(90.2%)의 연령 표기가 20·30대인 것은 **수집한 리뷰 안의 분포**이며 전체 고객 연령 비중이 아닙니다. 글로우픽 주제별 코딩 빈도는 현재 CSV만으로 재현할 수 없어 재검증이 필요합니다.

[원자료 품질 감사](analysis/task2/source_audit.md)에는 클릭 파일의 기간·영값과 리뷰의 분모·태그 불일치 사례를 기록했습니다. 산술 재계산과 독립 수치 검증은 아래 명령으로 재현할 수 있습니다.

```bash
python3 analysis/task2/audit_sources.py
python3 analysis/task2/verify2.py --numeric-only
```

위 명령은 현행 원자료와 저장된 계산값의 대조입니다(141항목, 불일치 0건). 과거 생성기 `calc2.py`의 아카이브 경로 정리는 남아 있어 전체 재생성 명령으로 안내하지 않습니다. PDF 빌더(`analysis/task2/build2.py`)와 `verify_pdf_sync.py`는 현행 보고서 **8편**(타깃·가설, 글로우 연결안, GS샵 X2 기획서·스토리보드·리뷰 분석, 국내 트렌드, 글로벌 트렌드, 피크 주)의 MD·PDF를 대조합니다 — 입력 해시·PDF 해시·표시 본문·빈 쪽 0건을 함께 확인하고, 재빌드는 `python3 analysis/task2/build2.py`입니다. `analysis/task2/`는 **검증·빌드 엔진 폴더**라 계산 스크립트와 결과 JSON·도표 SVG가 모여 있고 직접 열람할 필요는 없습니다. 도표는 `charts_domestic.py`·`charts_global.py`·`charts_peak.py`가 중간 산출물(`chartdata/`)만 읽어 `fig/domestic`·`fig/global`·`fig/peak`에 SVG로 다시 그리며, 수치·레이블은 재생성 전과 같고 색만 메디큐브 팔레트입니다. PDF 재생성 환경과 명령은 원자료 품질 감사 3장에 기록했습니다.

5060 기기 검색 5.6%와 이미용가전 클릭 74.3%는 도구·키워드·기간이 달라 같은 퍼널의 두 단계로 해석하지 않습니다. 클릭 파일에서 5개 키워드 중 3개가 0 또는 매우 낮고 원인도 미확인입니다. 2026년 5월 4일 주의 상승은 한 해의 한 주에 대한 관찰치이므로 시즌 효과로 확정하지 않습니다. 2030 콘텐츠와 5060 채널의 효과는 모두 미검증 상태입니다.

- **PDF 판본**: 현행 보고서 PDF 8편은 같은 빌더·CSS에서 생성·본문 대조했습니다. 이번 영상 편집안과 헬로키티 포스터는 별도 제작 기록이며, 기존 보고서 MD·PDF 본문은 변경하지 않았습니다. 14쪽 포트폴리오는 `analysis/task2/build_portfolio.py`가 reportlab으로 직접 조판하며, `verify_portfolio.py`(쪽수·본문·고정 문구·글리프·숫자 출처·여백·이미지)로 따로 검증합니다.
