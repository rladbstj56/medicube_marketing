# medicube_marketing

에이피알(APR) 메디큐브 마케팅 직무 지원을 준비하며 진행한 **기업분석·시장 리서치** 기록입니다.
네이버 데이터랩 검색 지수(국내)와 글로벌 1차 출처 검증, 구글 트렌드 실측 CSV 13종을 근거로, 지금 메디큐브의 수요가 어디로 옮겨갔는지와 지원 전략을 정리했습니다.

- **작업 기간**: 2026-11-18 ~ 2026-11-20
- **현재 문서 버전**: worklog `v2.8` · **타깃·가설 마케팅 전략 `v1.1`(2026-11-20, 30쪽 = Task 2)** · 국내 트렌드 분석 보고서 `v1.1`(2026-11-20, 22쪽) · **국내 피크 주 광고·이벤트 대조 분석 `v1.4`(2026-11-20, 21쪽 = 3단계)** · 글로벌 트렌드 분석 보고서 `v1.1` · 글로벌 사전근거 `v1.8` · (보관) 데이터랩 보고서 `v1.1` 33쪽 · 자료조사 `v1.0`
- **국내 보고서 기준**: 2026-11-20 슬랙으로 받은 **신규 10개 + 기존 2개 = 12개 원자료**만으로 다시 계산했고, 경쟁군은 **올리브영 매대 실측**(Top100·카테고리관·2025 어워즈·디바이스)으로 재선정했습니다. 구버전 33쪽 보고서의 경쟁군은 새 보고서 본문·차트에 쓰지 않았습니다. **전체 Top100은 v1.1에서 윤서 님이 2026-11-20 04:08 KST에 직접 저장한 실시간 랭킹 PDF(1차 실측)로 확정**했습니다 — 카테고리관·2025 어워즈만 크롤 캐시, 카테고리 Top10은 2차 집계입니다.
- **숫자 원칙**: 모든 수치는 원본 데이터에서 직접 계산했고, 확인하지 못한 값은 "확인 불가/미확인"으로 남겼습니다. 검색 지수는 **검색 관심도**이며 매출·구매력이 아닙니다.

## 경쟁군을 이 4개로 고른 이유 (보고서 `00-B` · 사전근거 `1.10 ⑦`)

- **범위**: 비교는 **K-뷰티 스킨케어 직접 경쟁군 안의 상대 점유**로 한정했습니다. 아모레퍼시픽(라네즈) 같은 1세대 대형 CeraVe·라 로슈포제·더 오디너리 같은 현지 매스는 체급·가격대·유통이 다른 축이라 같은 눈금에 세우지 않았습니다.
- **한도**: 구글 트렌드는 한 요청에 5개(메디큐브+4)까지라, ① 카테고리 일치(색조 롬앤·바디 일리윤·1세대 대형 라네즈/이니스프리 제외) ② 2026-11-19 실측 순위 근접도 ③ BIODANCE 공통 앵커 + COSRX 역성장 대조군으로 추렸습니다.
- **플랫폼 위상**: 영국은 뷰티 소비의 45.5%가 온라인·그 온라인의 35.1%가 아마존 UK(2023 MAT)이고 틱톡샵이 9.8%(2025 YTD·2위)입니다. 일본은 화장품 이커머스 비중이 10% 미만이고 그 온라인의 1위가 Qoo10(25~30% 이상)입니다 — 그래서 Qoo10 #38·아마존 JP 0개는 '일본 부진'이 아니라 채널 구조의 값입니다.

## 국내 경쟁군을 이 5개로 고른 이유 (국내 보고서 `00-B`)

국내 보고서는 **메디큐브 · 에스트라 · 메디힐 · 토리든 · 넘버즈인** 5개를 54주 같은 조건으로 조회했습니다. 데이터랩은 한 요청에 5개까지만 넣을 수 있어, 5개를 고정한 뒤 54주를 뽑았습니다.

- **근거는 매대 실측입니다** — **2026-11-20 04:08 KST 실시간 랭킹 Top100(1차 실측)** 에서 **에스트라 5개(1·12·37·46·73)** · **메디힐 5개(5·15·48·58·98)** · **넘버즈인 4개(30·39·56·57)** · **토리든 1개(9)** · 메디큐브 3개(26·61·81). 11-19 크롤 캐시(에스트라 1·11·48·51·85 · 메디힐 7·24·53·57·74 · 넘버즈인 31·44·55·64 · 토리든 14 · 메디큐브 28·86)와 비교하면 **경쟁군 5개의 개수는 그대로**이고 순위만 움직였습니다(보고서 `00-B` 표 0-3·0-3-A).
- **축이 겹치지 않게** 골랐습니다 — 에스트라=크림 1위(2025 어워즈) · 메디힐=패드 1위 · 토리든=에센스·마스크팩 1위 · 넘버즈인=로션 1위 · 메디큐브=디바이스 1~3위.
- **디바이스 세트**는 따로 **에이지알 · 마미케어 · 톰더글로우 · 쿼드쎄라 · 프라엘**로 조회했습니다(11-17 관측 1~3위 에이지알, 4·5위 마미케어, 8위 쿼드쎄라, 프라엘 10월 9위).
- **한계**: 전체 Top100은 **04:08 한 시점의 스냅숏**입니다(판매 순위라 하루 안에도 움직였습니다 — 아이오페 6→3개, 마미케어 브이쎄라 96→86위). 올리브영은 작업 환경 브라우저에서 차단되어 **카테고리관·어워즈는 크롤 캐시, 카테고리 Top10은 2차 집계(K-Beauty Digest)** 로 읽었습니다(보고서 `00-B`·`09`).

## Task 2 — 타깃과 가설: 두 개의 병목 (보고서 `메디큐브_국내_타깃가설_마케팅전략` v1.1)

국내 집중 2축으로 가설을 세우고, 판정 규칙을 **먼저 선언한 뒤** 12개 원자료로 검증했습니다. 결과는 둘 다 **부분 지지**입니다.

- **지표를 먼저 구분합니다(보고서 `00-B` 지표 이름표)** — 검색 = **네이버 데이터랩 검색어 트렌드의 5개 상대 검색 비중**(인지·관심), 클릭 = **네이버 쇼핑인사이트의 화장품/미용>스킨케어 5개 브랜드 클릭 비중**(구매 탐색). 디바이스·라인은 데이터랩 안의 별도 조회입니다.
- **비교군도 타깃마다 다릅니다** — 2030은 올리브영 스킨케어 매대의 주 고객층이라 **스킨케어 4사**(토리든·에스트라·메디힐·넘버즈인) 비교가 메인 근거이고, 5060은 그 매대의 주 고객이 아니므로 **디바이스 5사**(마미케어·에이지알·톰더글로우·쿼드쎄라·LG 프라엘) 비교를 메인으로 둡니다. 스킨케어 4사에서 나온 5060 클릭 21.4%는 **보조 지표**입니다.
- **5060 비교군의 한계** — 올리브영 랭킹은 2030 편향이라 5060에서 17.7%를 차지하는 **LG 프라엘**과 홈쇼핑 중심 쿼드쎄라 등이 Top100에 잡히지 않습니다. 보완은 홈쇼핑(GS샵·롯데홈쇼핑) 편성·판매 데이터와 쇼핑인사이트 이미용가전 5060 클릭입니다(보고서 `04-D`).

| 가설 | 데이터가 지지하는 것 | 데이터가 말하지 않는 것 | 판정 |
|---|---|---|---|
| **1. 2030 × 부스터 프로 미니** | 2030 검색 45.8% − 클릭 9.3% = **+36.5p.p.(5개 중 최대)** · 미니 비중 2030 3.0% vs 5060 0.9% · 리뷰의 "작고 가벼워 여행에 챙긴다" | 미니 검색 지수 **12.3 → 1.5(−87.7%)** · CRM 고객 데이터 없음 · 설문 미수신 | **부분 지지** — 수요는 없고 장면은 있음 |
| **2. 5060 × 선물·라이브** | 5060 클릭 **21.4% vs 9.3%(2.3배)** · **5/4 주 5060 +27.3%(2030 +8.3%)** · 5060 디바이스 **+37.8%** · 5060 부스터 프로 **+224.1%(연중 최고)** · 설 비중 64.1% · 블프 디바이스 비중 24.3% | 홈쇼핑 방송 주문·연령 구성 없음 · GS샵 5/9는 보도 1건 | **부분 지지** — 시점 강함·채널 얇음 |

- **전략**: 2030은 **릴스(발견) → 자사몰(전환) → CRM(재구매)**, 5060은 **가정의 달·설·블프 시즌 편성 + 홈쇼핑·라이브**(2027년 5월 제안서).
- **Task 3 연결**: 15초 주편 1편(미니 장면형) + 예비편 1편(5060 선물) — 콘티·AI 프롬프트·KPI 측정 설계까지 보고서 08장에 담았습니다.

## 3단계 — 피크 주에 실제로 무슨 일이 있었나 (보고서 `메디큐브_국내_피크주_광고_이벤트_대조분석`)

피크 주 Top 5(2026-11-02·08-03·05-04·03-02·06-29)를 **시장이 함께 오른 주**와 **메디큐브만의 주**로 갈랐습니다. 결론은 “5주 중 4주가 시장 공통”입니다.

- **올리브영 정기 세일은 공통 상승 이벤트** — 세일 5주 중 4주에서 경쟁사 2곳 이상이 검색 두 자릿수 상승(6월: 메디힐 +18.7%·넘버즈인 +14.7%·토리든 +13.1% / 9월: 에스트라 +16.5%·넘버즈인 +14.8% / 12월: 토리든 +27.1%·메디힐 +19.2%). 3월만 클릭에서 동반(메디큐브 +90.0%).
- **메디큐브 피크의 절반은 자사 신제품·모델 캠페인** — 부스터프로 X2 3/23(3/16 주 부스터 프로 +115.0%), 부스터 글로우 5/1 올영 선출시(5/4 주 글로우 +89.9%·5060 +27.3%), GS샵 X2 홈쇼핑 5/9, 조앤프렌즈 에디션 6/8.
- **단독 급등은 제품·랭킹 뉴스** — 넘버즈인 1/5 +322.6%(연중 최고), 메디힐 11/9 +119.5%(11월 올영픽 1위 패드), 에스트라 9/14(피부건강 엑스포 + 네이버 라이브). 원인을 못 찾은 주는 `[미확인]`으로 남겼고, v1.1~v1.4에서 Snipit 실측으로 **12주를 모두 채워 미확인 0건**으로 마감했습니다(2.30~2.33).
- **8/3 주는 디바이스 4사가 동시에 움직인 주**(v1.1 Snipit 실측, 게시일 2026-07-27~08-09) — 메디큐브 **11주년 대감사제**(8/3~8/24, 디바이스 11% 쿠폰·마스크팩 증정·화요특가), 쿼드쎄라 **GS샵 홈쇼핑 8/3 11:55 + 신제품 틴즈 카카오 LIVE**, LG 프라엘 **멜라빔 토닝 7/30 출시 + 회사원A 마켓 8/6**, 톰더글로우 **kbp 한정판 + 조회 상위 2% 여행 소구**. 표 5-3이 12개 소재를 게시일·게재일수와 함께 정리했습니다.
