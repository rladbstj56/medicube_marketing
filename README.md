# medicube_marketing

에이피아르(APR) 메디큐브 마케팅 직무 지원을 준비하며 진행한 **기업분석·시장 리서치** 기록입니다.
네이버 데이터랩 검색 지수(국내)와 글로벌 1차 출처 검증, 구글 트렌드 실측 CSV를 근거로, 지금 메디큐브의 수요가 어디로 옮겨갔는지와 지원 전략을 정리했습니다.

- **작업 기간**: 2026-11-18 ~ 2026-11-20
- **현재 문서 버전**: worklog `v1.6` · 글로벌 리서치 `v1.6` · 데이터랩 보고서 `v1.1` · 자료조사 `v1.0`
- **숫자 원칙**: 모든 수치는 원본 데이터에서 직접 계산했고, 확인하지 못한 값은 "확인 불가/미확인"으로 남겼습니다. 검색 지수는 **검색 관심도**이며 매출·구매력이 아닙니다.

## 문서 버전 규칙

1. **저장소 안에서는 파일명을 고정**합니다(`worklog.md`, `reports/메디큐브_네이버데이터랩_트렌드_분석보고서.md`).
   파일명을 `_v1.1`, `_v1.2`로 바꿔 새 파일로 올리면 Git이 "삭제 + 추가"로 인식해 줄 단위 변경 이력이 끊깁니다.
2. **버전은 문서 안과 Git 태그로** 남깁니다. 각 문서 첫머리에 `버전 · 최종 수정 시각 · 직전 대비 변경 요약 · 버전 이력표`가 있고, 커밋에는 `v1.x` 태그를 찍습니다.
3. **전달 파일명에도 버전을 넣지 않습니다**(2026-11-20 윤서 님 지시). 슬랙·메일로 보낼 때도 `APR_지원_worklog_2026-11-19.md`처럼 **날짜까지만** 쓰고, 버전은 문서 첫머리와 Git 태그로만 남깁니다.

- 커밋 시각은 문서 작성 시각이 아니라 **저장소에 올린 시각**입니다.

## 재현

- 데이터랩 엑셀 10개를 `openpyxl`로 전 행 파싱(54주 × 5주제어 × 10파일 = 2,700값)해 보고서 수치를 재계산했습니다.
- 데이터랩 지수는 **키워드 간 상대 지수(최대 100 정규화)** 입니다. 파일마다 기준 키워드가 달라 **파일 간 절대 비교는 하지 않았고**, 파일 안에서의 비중·배수로만 읽었습니다.
- 구글 트렌드 CSV는 원자료 그대로 두고 python `csv`로 집계했습니다 — 유럽 30개국 순위, 영국 대비 배수(독일 3.86배·이탈리아 3.0배·스페인 2.16배), 시계열 53주 평균(57.6)·앞뒤 13주 평균(38.9→79.9, +105.3%). 계산 내역은 `research/` 문서의 00-C(C-4)에 있습니다.
- 검증은 원본 재파싱·독립 재계산(404건)·수치 토큰 대조로 했고, 불일치 0건입니다.

## 한계

- 데이터랩 지수는 **검색 관심도**이며 매출·구매력이 아닙니다. 보고서에는 이 구분을 명시했습니다.
- 글로벌 트래픽·검색 수치는 패널 기반 추정치로, 아마존·올리브영·틱톡샵·앱 매출은 포함되지 않습니다.
- 구글 트렌드 지역별 값은 국가 내 비율이라 작은 시장이 과대평가될 수 있습니다(캄보디아 100·리투아니아 56 > 영국 54). 그래서 판정 문구는 **'유럽 주요국 1위'**로 한정했습니다. **'유럽 주요국'의 정의(9개국: 아마존 유럽 주요 스토어 UK·DE·FR·IT·ES / 에이피알 공시 종속기업 UK·NL이 있는 서유럽 6개국 + 폴란드·벨기에·스위스)와 리투아니아 제외 근거**는 `worklog.md` 2.22 · `research/` 문서 **C-7**에 있습니다.
- F세트는 `medicube` 단독 조회라 **경쟁사 대비 성과는 이 데이터로 알 수 없습니다.** 경쟁사 비교는 다음 단계(국가별 A·C 세트)에서 채웁니다.
