# 글로우 리뷰 분석과 2030 전략 연결

> v1.1 · 2026-11-20 · 전략 재검토 및 코딩 경계 사례 정정. 2단계 결과와 3단계 검증 입력안. 글로우 우선 여부·매출 역할 미확정.

## 1. 현재 판단

**글로우는 ‘보습·피부결 관리를 원하는 사람이 사용 조건을 확인하고 선택하도록 돕는 콘텐츠’의 검증 후보로 구체화할 수 있음.** 2030 전체에게 적합하다거나 미니보다 매출 효과가 크다고 판정할 자료는 아직 없음. 리뷰에서 보이는 기대와 사용 장벽을 콘텐츠 설계의 입력으로 삼음.

재검토 판정은 **조건부 적절: 구매 검토를 돕는 콘텐츠 가설**임. 현재 안만으로 신규 수요 규모·2030에 대한 상대적 적합성·판매 효과·경쟁사 대비 차별성을 입증하지 못함. 기존안은 선택 안내에 치우쳐 제품을 검토할 이유가 약했으므로, 구매 고민을 먼저 제시하고 구체적 기능·차별점은 3단계 제품 메시지 대조와 5단계 경쟁사 비교에서 채우도록 수정함. 조건을 확인하라는 말 자체를 최종 핵심 가치로 삼지 않음.

AI가 공식몰 217건과 글로우픽 15건을 전수 읽고 1차 의미 코딩함. 서로 다른 출처의 리뷰 232행이며 232명의 독립 고객을 뜻하지 않음. 복수 코드 허용, 독립 재코딩 미실시. 코딩의 근거 원문은 [코딩표](../data/reviews/glow_reviews_coded_2026-11-20.csv), 포함·제외 기준은 [코드북](../analysis/task2/glow_review_codebook.md)에 있음.

## 4. 2030 전략 가설의 구체화

**대상 정의(실험 모집 기준 제안)**: 노출 전에 보습·피부결 홈케어 관심을 확인한 20–39세. 2030은 이번 프로젝트에서 선택한 실험 범위이며 다른 연령보다 더 적합하다고 검증된 결과는 아님. 모집 시 관심과 현재 기기 보유를 같은 방식으로 확인하고, 콘텐츠를 보고 난 후의 관심·사용 의향으로 실험 대상자를 다시 고르지 않음. 성별 제한은 이 리뷰만으로 확정하지 않음.

- **문제 제시 후보**: ‘기초는 바르는데, 피부결 고민은 남아 있나요?’
- **제품 검토 이유 후보**: 보습·피부결 홈케어를 원하는 사람에게 글로우의 관리 목적과 사용 방식을 설명함. 구체적인 기능·차별점·효능 문구는 공식 정보 대조 후 채우며 현재는 완성된 판매 약속으로 보지 않음.
- **약속의 범위**: 고민과 사용 조건을 비교해 제품을 선택하도록 돕는 정보 제공. 피부 개선·트러블 없음·시술 대체·단기간 전후 차이를 보장하지 않음.
- **세부 비교군**: 기기 미보유자와 기존 보유자를 노출 전 구분해 분석함. 기존 보유자에게는 ‘더 사야 한다’는 메시지보다 현재 기기와 목적이 어떻게 다른지 보여줄 근거가 필요함. 두 집단의 규모·구매 의향과 우선순위는 미확인임.
- **채널 제안**: 릴스·숏폼 → 제품 목적·사용 조건 비교 랜딩 → 공식 상품페이지. 리뷰만으로 채널 효율을 검증한 것은 아니므로 파일럿 후보로 둠.
- **구매 전 장벽**: 지출 부담, 사용 시간, 화장품 병용·추가 소모량, 조작·일시정지, 개인 피부 반응. 공식 사양으로 확인된 항목만 최종 안내에 넣음.
- **랜딩 제목 후보**: ‘부스터 글로우, 내 관리 목적에 맞을까요?’
- **CTA 후보**: ‘사용 조건과 제품 차이 확인하기.’

## 5. 제작으로 연결할 15초 구조 초안

아래는 제품 선택 판정 전 **비교 안내형 콘티의 구조**임. 글로우를 최종 주편으로 확정한 콘티가 아님. 제작에는 사용 권한이 확인된 제품 소재와 자체 제작 장면을 사용함.

| 구간 | 장면 목적·화면 | 자막 후보 | 확인할 근거 |
|---|---|---|---|
| 0–3초 | 스킨케어 준비와 글로우 제품 정물. 인물의 피부 전후 비교 없음 | ‘기초는 바르는데, 피부결 고민은 남아 있나요?’ | 구매 전 고민 단서. 모든 사람의 증상으로 단정하지 않음 |
| 3–6초 | ‘보습·피부결 홈케어’ 목적 카드 | ‘글로우가 내 목적에 맞을지’ | 기능·차별점 표현은 3단계 공식 정보 대조 후 구체화 |
| 6–10초 | 공식 가이드를 확인하는 손, 시간·준비물 체크 UI | ‘사용 시간과 준비물도 확인하고’ | 시간·소모품 장벽. 수치·방법은 공식 원문 확인 필요 |
| 10–13초 | 기존 기기와 목적 비교 카드 | ‘지금 쓰는 기기와 비교하세요’ | 기존 프로 보유자 만족·불만 양쪽 사례 |
| 13–15초 | 제품 정물·CTA | ‘내 루틴에 맞는지 확인하기’ | 비교 안내 랜딩 연결 |

자극·침투를 시각화한 피부 단면, 병원과 동등한 효과, 실제 사용시간보다 짧아 보이는 시연은 넣지 않음. 경쟁사와의 키워드·장면 중복은 5단계에서 점검해야 함.

## 6. 실험으로 확인할 것

**기획 가설**: 같은 제품·가격·채널 조건에서 ‘관리 목적+사용 조건 비교’ 소재가 일반적인 제품 소개 소재보다 제품 탐색을 늘리는가? 이 가설은 제품의 임상 효과나 글로우의 매출 주력 여부를 검증하지 않음.

| 설계 항목 | 제안 |
|---|---|
| A | 공식 확인 특징 중심의 일반 제품 소개 |
| B | 보습·피부결 고민과 사용 조건 비교 안내 |
| 고정 조건 | 제품·가격·혜택·CTA 목적지·소재 길이·게재 조건 |
| 배정 | 사용자 단위 1:1 고정 배정, 교차 노출 관리 가능할 때 실행 |
| 사전 분류 | 관심·기기 보유 여부는 배정 전 동일 방식으로 확인. 보유 집단별 효과 차이는 탐색 결과로 두고 전체 1차 지표와 구분 |
| 1차 지표 | 배정 후 7일 내 상품페이지 방문 사용자 / 배정 사용자 |
| 보조 지표 | 3초 조회·비교 안내 완독·장바구니·구매. 분모를 각각 정의 |
| 해석 조건 | 노출·방문 계측 누락과 배정 불균형 점검. 실제 유입 기준선·MDE 확보 후 표본 수와 기간 결정 |
| 보류 항목 | ROAS·매출 상승 예상치, 실제 성과, 검증 완료 판정 |

플랫폼이 사용자 배정·7일 방문 연결을 제공하지 않으면 이 설계의 인과 판정을 그대로 적용할 수 없음. 제공되는 실험 기능·자사 계측 조건에 맞춰 지표와 모집단을 먼저 수정해야 함.

이 A/B는 글로우라는 같은 제품 안에서 **메시지 구성 전체**를 비교함. 보습 키워드만의 효과, 사용 시간 안내만의 효과, 글로우 대 미니 제품 효과를 각각 입증하지 못함. 랜딩을 거쳐 상품페이지로 이동하므로 랜딩 방문율과 상품페이지 방문율도 구분함. 상품 탐색 증가가 실제 구매 증가를 보장하지 않음.

## 7. 3단계 판정에 필요한 확인

기존 저장된 `num2.json`에서 글로우의 2030 최근 13주 라인 검색 비중은 27.8%이나 직전 4주 대비 지수 변화는 −24.6%임. 따라서 ‘글로우 관심이 계속 상승한다’는 주장도 현재 자료로 확정할 수 없음. 글로우의 시작 구간이 0이므로 출시 전부터의 증가율을 미니와 같은 방법으로 비교하지 않음.

다음 판정에서는 원자료로 **출시 후 동일 기간의 글로우·미니·프로 추이**, 프로 키워드의 X2 포함 범위, 런칭·마켓·할인 주의 영향을 확인해야 함. 사용 시간·모드·사용 부위·화장품 병용·주의사항은 공식 상품 설명이나 설명서로 대조해야 함. 이 절차 후 ‘글로우 우선 / 조건부 / 근거 부족’ 중 판정하고 위 콘티의 제품·자막을 확정함.

## 8. 기존 계획과의 관계

- **합의된 3단계**: ‘출시 후 글로우 검색 추이와 미니의 하락, 리뷰의 장단점, 제품별 메시지를 함께 대조’하고 ‘글로우 우선 / 조건부 / 근거 부족’으로 판정하기로 했음. 따라서 검색 추이 대조는 원래 계획의 핵심 작업임.
- **공식 가이드 대조의 위치**: 계획에 ‘공식 가이드 검증’이라는 별도 단계명은 없었음. ‘제품별 메시지 대조’, 제작 기준의 ‘제품에서 실제 확인된 특징·금지할 과장 표현’과 최종 ‘제품 표현 검수’를 수행하기 위해 구체화한 확인 절차임. 리뷰 속 시간·사용 부위·병용법을 광고에 옮길 때 사실 여부를 확인하는 역할임.
- **판정 대상 구분**: 검색과 리뷰는 이번 포트폴리오에서 어느 제품 콘텐츠를 먼저 만들지 판단하는 근거임. 가이드는 표현·사용 장면의 정확성을 확인함. 가이드에 맞는다는 사실이 글로우의 수요·매출 우위를 증명하지 않음.
- **완료 범위**: 현재 단계에서는 전략 가설과 코딩을 재검토함. 다음 단계의 검색 재분석·가이드 대조를 완료했다고 표시하지 않음. 매출 접근이나 임상 검증을 새 필수 관문으로 추가하지 않고, 확인 가능한 공개 근거로 콘텐츠 우선순위를 조건부 결정할 수 있음.
