# 글로우 리뷰 분석과 2030 전략 연결

> v1.4 · 2026-11-20 · 3단계 판정: 글로우를 2030 콘텐츠 실험 1순위로 조건부 채택. 아래 1–8장은 판정 전 가설·검토 기록이며, 현행 판정·콘티·메시지 근거는 9–12장을 기준으로 읽음. 공식몰 키워드·리뷰 주제·경쟁 사례의 연결 기준을 추가함. 매출 주력 여부 미확정.

## 1. 현재 판단

**글로우는 ‘보습·피부결 관리를 원하는 사람이 사용 조건을 확인하고 선택하도록 돕는 콘텐츠’의 검증 후보로 구체화할 수 있음.** 2030 전체에게 적합하다거나 미니보다 매출 효과가 크다고 판정할 자료는 아직 없음. 리뷰에서 보이는 기대와 사용 장벽을 콘텐츠 설계의 입력으로 삼음.

재검토 판정은 **조건부 적절: 구매 검토를 돕는 콘텐츠 가설**임. 현재 안만으로 신규 수요 규모·2030에 대한 상대적 적합성·판매 효과·경쟁사 대비 차별성을 입증하지 못함. 기존안은 선택 안내에 치우쳐 제품을 검토할 이유가 약했으므로, 구매 고민을 먼저 제시하고 구체적 기능·차별점은 3단계 제품 메시지 대조와 5단계 경쟁사 비교에서 채우도록 수정함. 조건을 확인하라는 말 자체를 최종 핵심 가치로 삼지 않음.

AI가 공식몰 217건과 글로우픽 15건을 전수 읽고 1차 의미 코딩함. 서로 다른 출처의 리뷰 232행이며 232명의 독립 고객을 뜻하지 않음. 복수 코드 허용, 독립 재코딩 미실시. 코딩의 근거 원문은 [코딩표](../data/reviews/glow_reviews_coded_2026-11-20.csv), 포함·제외 기준은 [코드북](../analysis/task2/glow_review_codebook.md)에 있음.

공식몰에서 명시적 미사용 3건과 선물 수령자 관련 3건을 구분함. 선물 수령자 경험은 구매자 본인 경험으로 합치지 않음. 표의 분모는 전체 수집 행으로 통일했으며 ‘효과를 확인한 사용자의 비율’을 계산하지 않음. 공식몰에는 연령 필드가 없고 글로우픽 15건의 표시 연령이 20–39세임. 두 출처를 합쳐 2030 구성비를 만들지 않음.

## 4. 2030 전략 가설의 구체화

**대상 정의(실험 모집 기준 제안)**: 노출 전에 보습·피부결 홈케어 관심을 확인한 20–39세. 2030은 이번 프로젝트에서 선택한 실험 범위이며 다른 연령보다 더 적합하다고 검증된 결과는 아님. 모집 시 관심과 현재 기기 보유를 같은 방식으로 확인하고, 콘텐츠를 보고 난 후의 관심·사용 의향으로 실험 대상자를 다시 고르지 않음. 성별 제한은 이 리뷰만으로 확정하지 않음.

- **문제 제시 후보**: ‘기초는 바르는데, 피부결 고민은 남아 있나요?’
- **제품 검토 이유 후보**: 보습·피부결 홈케어를 원하는 사람에게 글로우의 관리 목적과 사용 방식을 설명함. 구체적인 기능·차별점·효능 문구는 공식 정보 대조 후 채우며 현재는 완성된 판매 약속으로 보지 않음.
- **약속의 범위**: 고민과 사용 조건을 비교해 제품을 선택하도록 돕는 정보 제공. 피부 개선·트러블 없음·시술 대체·단기간 전후 차이를 보장하지 않음.
- **세부 비교군**: 기기 미보유자와 기존 보유자를 노출 전 구분해 분석함. 기존 보유자에게는 ‘더 사야 한다’는 메시지보다 현재 기기와 목적이 어떻게 다른지 보여줄 근거가 필요함. 두 집단의 규모·구매 의향과 우선순위는 미확인임.
- **채널 제안**: 릴스·숏폼 → 제품 목적·사용 조건 비교 랜딩 → 공식 상품페이지. 리뷰만으로 채널 효율을 검증한 것은 아니므로 파일럿 후보로 둠.
- **구매 전 장벽**: 지출 부담, 사용 시간, 화장품 병용·추가 소모량, 조작·일시정지, 개인 피부 반응. 공식 사양으로 확인된 항목만 최종 안내에 넣음.
- **랜딩 제목 후보**: ‘부스터 글로우, 내 관리 목적에 맞을까요?’
- **CTA 후보**: ‘사용 조건과 제품 차이 확인하기.’

## 5. 제작으로 연결할 15초 구조 초안

아래는 제품 선택 판정 전 **비교 안내형 콘티의 구조**임. 글로우를 최종 주편으로 확정한 콘티가 아님. 제작에는 사용 권한이 확인된 제품 소재와 자체 제작 장면을 사용함.

| 구간 | 장면 목적·화면 | 자막 후보 | 확인할 근거 |
|---|---|---|---|
| 0–3초 | 스킨케어 준비와 글로우 제품 정물. 인물의 피부 전후 비교 없음 | ‘기초는 바르는데, 피부결 고민은 남아 있나요?’ | 구매 전 고민 단서. 모든 사람의 증상으로 단정하지 않음 |
| 3–6초 | ‘보습·피부결 홈케어’ 목적 카드 | ‘글로우가 내 목적에 맞을지’ | 기능·차별점 표현은 3단계 공식 정보 대조 후 구체화 |
| 6–10초 | 공식 가이드를 확인하는 손, 시간·준비물 체크 UI | ‘사용 시간과 준비물도 확인하고’ | 시간·소모품 장벽. 수치·방법은 공식 원문 확인 필요 |
| 10–13초 | 기존 기기와 목적 비교 카드 | ‘지금 쓰는 기기와 비교하세요’ | 기존 프로 보유자 만족·불만 양쪽 사례 |
| 13–15초 | 제품 정물·CTA | ‘내 루틴에 맞는지 확인하기’ | 비교 안내 랜딩 연결 |

자극·침투를 시각화한 피부 단면, 병원과 동등한 효과, 실제 사용시간보다 짧아 보이는 시연은 넣지 않음. 경쟁사와의 키워드·장면 중복은 5단계에서 점검해야 함.

## 6. 향후 자사 데이터 접근 시의 실험 설계안

현재 포트폴리오에서는 광고 계정의 무작위 배정·노출 로그·상품페이지 방문 로그와 주문 데이터를 사용할 수 없음. 따라서 아래 A/B는 **실행 예정이나 현재 검증 경로가 아니라 조건부 설계 예시**임. 이 과제의 결과물은 공개 자료로 제품·메시지를 선택한 근거, 원문 추적표, 경쟁 소재 대조, 제작한 콘텐츠의 사실·표현 검수까지임. 콘텐츠 효과·2030 전환율·매출 효과는 판정하지 않음.

**향후 측정할 기획 가설**: 같은 제품·가격·채널 조건에서 ‘관리 목적+사용 조건 비교’ 소재가 일반적인 제품 소개 소재보다 제품 탐색을 늘리는가? 이 가설은 제품의 임상 효과나 글로우의 매출 주력 여부를 검증하지 않음.

| 설계 항목 | 데이터 접근권이 생긴 경우의 제안 |
|---|---|
| A | 공식 확인 특징 중심의 일반 제품 소개 |
| B | 보습·피부결 고민과 사용 조건 비교 안내 |
| 고정 조건 | 제품·가격·혜택·CTA 목적지·소재 길이·게재 조건 |
| 배정 | 사용자 단위 1:1 고정 배정, 교차 노출 관리 가능할 때 실행 |
| 사전 분류 | 관심·기기 보유 여부는 배정 전 동일 방식으로 확인. 보유 집단별 효과 차이는 탐색 결과로 두고 전체 1차 지표와 구분 |
| 1차 지표 | 배정 후 7일 내 상품페이지 방문 사용자 / 배정 사용자 |
| 보조 지표 | 3초 조회·비교 안내 완독·장바구니·구매. 분모를 각각 정의 |
| 해석 조건 | 노출·방문 계측 누락과 배정 불균형 점검. 실제 유입 기준선·MDE 확보 후 표본 수와 기간 결정 |
| 보류 항목 | ROAS·매출 상승 예상치, 실제 성과, 검증 완료 판정 |

현재는 사용자 배정·7일 방문 연결 자료가 없으므로 이 설계의 인과 판정을 실행하거나 결과를 보고할 수 없음. 제공되는 실험 기능·자사 계측 조건에 맞춰 지표와 모집단을 먼저 수정해야 함.

이 A/B는 글로우라는 같은 제품 안에서 **메시지 구성 전체**를 비교함. 보습 키워드만의 효과, 사용 시간 안내만의 효과, 글로우 대 미니 제품 효과를 각각 입증하지 못함. 랜딩을 거쳐 상품페이지로 이동하므로 랜딩 방문율과 상품페이지 방문율도 구분함. 상품 탐색 증가가 실제 구매 증가를 보장하지 않음.

## 7. 3단계 판정에 필요한 확인

기존 저장된 `num2.json`에서 글로우의 2030 최근 13주 라인 검색 비중은 27.8%이나 직전 4주 대비 지수 변화는 −24.6%임. 따라서 ‘글로우 관심이 계속 상승한다’는 주장도 현재 자료로 확정할 수 없음. 글로우의 시작 구간이 0이므로 출시 전부터의 증가율을 미니와 같은 방법으로 비교하지 않음.

다음 판정에서는 원자료로 **출시 후 동일 기간의 글로우·미니·프로 추이**, 프로 키워드의 X2 포함 범위, 런칭·마켓·할인 주의 영향을 확인해야 함. 사용 시간·모드·사용 부위·화장품 병용·주의사항은 공식 상품 설명이나 설명서로 대조해야 함. 이 절차 후 ‘글로우 우선 / 조건부 / 근거 부족’ 중 판정하고 위 콘티의 제품·자막을 확정함.

## 8. 기존 계획과의 관계

- **합의된 3단계**: ‘출시 후 글로우 검색 추이와 미니의 하락, 리뷰의 장단점, 제품별 메시지를 함께 대조’하고 ‘글로우 우선 / 조건부 / 근거 부족’으로 판정하기로 했음. 따라서 검색 추이 대조는 원래 계획의 핵심 작업임.
- **공식 가이드 대조의 위치**: 계획에 ‘공식 가이드 검증’이라는 별도 단계명은 없었음. ‘제품별 메시지 대조’, 제작 기준의 ‘제품에서 실제 확인된 특징·금지할 과장 표현’과 최종 ‘제품 표현 검수’를 수행하기 위해 구체화한 확인 절차임. 리뷰 속 시간·사용 부위·병용법을 광고에 옮길 때 사실 여부를 확인하는 역할임.
- **판정 대상 구분**: 검색과 리뷰는 이번 포트폴리오에서 어느 제품 콘텐츠를 먼저 만들지 판단하는 근거임. 가이드는 표현·사용 장면의 정확성을 확인함. 가이드에 맞는다는 사실이 글로우의 수요·매출 우위를 증명하지 않음.
- **완료 범위**: 현재 단계에서는 전략 가설과 코딩을 재검토함. 다음 단계의 검색 재분석·가이드 대조를 완료했다고 표시하지 않음. 매출 접근이나 임상 검증을 새 필수 관문으로 추가하지 않고, 확인 가능한 공개 근거로 콘텐츠 우선순위를 조건부 결정할 수 있음.

## 9. 3단계 판정: 글로우 조건부 채택

**이번 포트폴리오에서 기존 미니 주편안 대신 글로우를 콘텐츠 실험 1순위로 선택함.** 제품 선택의 근거는 공개 검색 관심·리뷰의 구체적 선택 고민·정확하게 설명 가능한 제품 특징임. 글로우가 미니 플러스·프로보다 잘 팔리거나 광고 성과가 좋다고 판정한 것은 아님.

피클의 세 축을 적용하되 최근 하락의 원인을 분리해냈다고 주장하지 않고, ‘제품 간 역할이 전혀 겹치지 않아야 한다’를 요건으로 삼지 않음. 세 축에 점수를 임의 부여하거나 사후 기준을 통계 검증처럼 표시하지 않음.

### 검색 관심: 수준 우위와 최근 하락을 함께 확인

원자료는 동일 요청의 **여성 19–39세** 제품명 검색임. 2030의 남성까지 포함한 자료가 아님. 5/1 선출시 뒤 첫 완전주인 5/4부터 XLSX의 마지막 주인 11/9까지 비교함. 11/20 현재까지의 모든 주를 추가 수집한 것은 아님.

| 비교 범위 | 주 수 | 글로우가 미니보다 높은 주 | 지수 합의 글로우/미니 비율 |
|---|---:|---:|---:|
| 5/4–11/9 전체 | 28 | 28 | 7.51배 |
| 첫 4주 제외 | 24 | 24 | 8.13배 |
| 글로우 상위 피크 3주 제외 | 25 | 25 | 6.90배 |
| 최근 13주 | 13 | 13 | 9.46배 |
| 최근 4주 | 4 | 4 | 10.15배 |

피크 제외일은 6/29·9/14·9/21임. 제외 방식은 탐색적 민감도 점검이며 행사 주를 전수 제거한 자료가 아님. 표의 비율은 같은 조회에서의 검색 지수 비율로 실제 검색 횟수나 매출 비율을 뜻하지 않음.

최근 4주(10/19–11/9) 평균은 직전 4주(9/21–10/12)보다 글로우 −24.6%, 미니 −25.2%, 프로 묶음 −16.8%임. 글로우도 하락했지만 동시에 미니보다 높은 수준을 유지함. 이 값만으로 하락의 원인·장기 성장·브랜드 검색의 이동을 판정하지 않음.

여기서 ‘최근’은 오늘이 아니라 **보유 XLSX의 마지막 관측 주 기준**임. 주간 지수 네 개의 단순평균이며 이동평균 추세선을 추정한 것이 아님. 날짜는 각 주의 시작일임.

| 구분 | 해당 4개 주의 시작일 | 글로우 주간 검색지수 | 평균 |
|---|---|---|---:|
| 직전 4주 | 9/21・9/28・10/5・10/12 | 33.71843・28.80171・23.83127・19.98925 | 26.585165 |
| 마지막 4주 | 10/19・10/26・11/2・11/9 | 22.03116・19.39817・21.70875・17.00698 | 20.036265 |

변화율은 `(20.036265 / 26.585165 − 1) × 100 = −24.6%`임. 주간 정규화 검색지수의 평균 변화이며 실제 검색 횟수·매출·검색 비중의 변화율이 아님. 비교 구간을 바꾸면 값도 달라지므로 날짜와 산식을 함께 기재함.

원본 결과 화면에서 프로 묶음에 `부스터프로x2`가 포함됨을 확인함. 미니 묶음에는 `부스터프로미니`·`부스터미니`가 있고 미니 플러스는 명시되지 않음. 따라서 **미니 검색 감소를 미니 플러스의 수요 감소로 바꾸어 쓰지 않음**. 미니 플러스와의 검색 우위까지 주장하려면 별도 조회가 필요하지만, 원래 미니 콘텐츠안 대신 실험할 제품을 고르는 이번 판단을 보류시킬 조건으로 삼지는 않음.

재현: `python3 analysis/task2/compare_glow_search.py`. 결과와 입력 SHA256은 `analysis/task2/glow_search_comparison.json`, 주별 표는 `data/reviews/glow_search_weekly_2030.csv`에 보존함. 생성기는 기존 calc2와 별개로 해당 한 파일만 읽으므로 아카이브 입력에 의존하지 않음.

### 리뷰·메시지: 실험할 목적과 반대 근거가 구체적임

보습·피부결 경험과 시간·지출 부담을 실제 원문에 연결할 수 있음(2–3장). 긍정 경험을 효과 보장으로 바꾸지 않고 ‘어떤 관리 목적과 사용 조건을 검토할지’ 제시하는 데 사용함. 글로우픽 15건의 20–39세 표시와 공식몰의 연령 미표시는 각각 유지함. 같은 피부 고민이 다른 연령에도 있을 수 있으므로 2030에 독점적인 니즈라고 주장하지 않음.

[공식 비교표](https://www.themedicube.co.kr/product_compare.html)에서 글로우는 물방울 초음파, 미니 플러스는 글로우 포레이션으로 구분되지만 흡수·광채 효익은 겹침. 차별화는 ‘글로우만 보습된다’가 아니라 기술·관리 시간·준비물의 선택 정보로 구체화함. 광채라는 단어만으로 경쟁사와 차별화됐다고 판단하지 않으며 경쟁사 대조는 5단계에서 수행함.

### 공식 정보·제작: 비시연형 15초 콘텐츠로 구현 가능

[공식 정보 대조표](../analysis/task2/glow_product_verification.md)에 비교표·FAQ·원본 상세 이미지 확인 범위를 기록함. 12분 안내·젤 크림 등의 매개체·모드 구성을 확인함. 모든 사용 부위·주의사항의 전수 검증을 완료한 것은 아니므로 이번 콘티에서 얼굴 접촉 시연·단계별 사용 지시는 제외함.

공식 사진의 광고 재사용 권한은 미확인임. 제작 가능한 기본안은 자체 제작 생활 장면+제품명 텍스트+정보 카드로 구성함. 촬영 가능한 미니를 가진 사실은 이번 제품 선택 근거로 사용하지 않음.

### 조건의 의미

‘조건부’는 분석을 끝없이 보류한다는 뜻이 아님. **글로우 비시연형 주편 1편을 기획·제작할 제품으로 선택하되, 미니 플러스 대비 수요·매출 우위·모든 피부에 대한 효과는 주장하지 않는 범위**임. 이미지 재사용이나 피부 접촉 시연을 추가할 경우 해당 권한·가이드를 확인함. 실제 광고 효과 판정은 집행 자료로 별도 수행함.

## 10. 채택할 2030 전략

- **콘텐츠 기획 대상**: 보습·피부결 홈케어 관심이 있는 20–39세 여성. 검색 근거는 19–39세여서 19세가 포함된다는 한계를 남김. 남성 확장은 현 자료에서 검증되지 않았으므로 별도 탐색으로 둠.
- **소비자 고민**: 기초제품을 사용 중이지만 홈케어 기기를 더할지, 어떤 목적과 시간에 맞춰 선택할지 고민함. 기존 보유자는 추가 구매 필요성도 확인하려 함.
- **핵심 메시지**: ‘보습·피부결 홈케어를 고민한다면, 물방울 초음파 글로우의 관리 방식부터 확인하세요.’
- **구체적 선택 정보**: 물방울 초음파 기술, 12분 안내, 수분감 있는 매개체와 함께 사용하는 방식. 사용 시간·주기는 피부 상태에 맞춰 공식 가이드를 따름.
- **콘텐츠 흐름 제안**: 릴스/숏폼의 고민 제시 → 사용 시간·준비물·제품 차이를 설명하는 랜딩 초안 → 공식 상품페이지. 채널별 집행 효율은 현재 평가할 수 없음.
- **랜딩 상단**: ‘글로우, 내 홈케어 루틴에 맞을까요?’ → 관리 목적·기술 → 시간·준비물 → 기존 기기와 비교 → 사용 가이드·상품페이지.
- **현재 완료 기준**: 공식 문구와 콘티 자막의 근거 추적, 리뷰 반대 사례 반영, 경쟁사 표현 중복 검수, 15초 제작물의 제품 정보·자막·링크 확인. 이 검수는 메시지 효과 검증이 아님. 상품페이지 방문 사용자 비율은 6장의 향후 실험 설계에만 해당함.

## 11. 촬영 없이 제작할 15초 콘티 v1.1

기본안은 제품 사용자가 등장하지 않는 자체 제작 생활 비주얼·모션 타이포임. 정물 제품 사진이 없어도 구현할 수 있음. 후기 인용·AI 사용 후기·의학적 단면 이미지는 사용하지 않음.

| 시간 | 화면·장면 목적 | 화면 자막 | 제작·검수 지시 |
|---|---|---|---|
| 0–3초 | 세면대 옆 스킨케어 준비 공간. 기기 사용·피부 결과 없이 고민 제시 | ‘촉촉함과 피부결, 내 홈케어의 기준은?’ | O03·R01·R02에서 고민 도출. 자체 생성 공간. 브랜드 제품 용기를 임의로 재현하지 않음. 경쟁사 고유 후킹 대조 전의 초안 |
| 3–6초 | 로즈 계열 배경에 제품명 카드 등장 | ‘부스터 글로우 / 3중 주파수 물방울 초음파’ | O02·O06 기술명 사용. 효과 보장이나 전문기관 동등성 표현 없음. 공식 사진은 권한 확인 시에만 대체 삽입 |
| 6–10초 | 12분 정보 카드와 느리게 움직이는 시계 그래픽 | ‘선택 전, 12분 루틴부터 확인하세요’ | 15초 영상 안에 관리가 끝나는 연출 금지. 하단 ‘사용 시간·주기는 공식 가이드 확인’ |
| 10–13초 | 젤 크림을 준비하는 손 대신 무브먼트 없는 텍스트 카드 | ‘수분감 있는 매개체와 함께’ | 공식 FAQ 범위의 표현. 특정 크림과 시너지·모든 화장품 호환 보장 금지 |
| 13–15초 | 제품명·랜딩 CTA 유지 | ‘내 루틴에 맞는 사용법 확인하기’ | CTA는 비교 안내 랜딩으로 연결. 혜택·가격은 넣지 않아 확인되지 않은 행사 약속을 피함 |

음향은 잔잔한 배경음 1개와 카드 전환 효과음으로 구성함. 내레이션 없이도 이해되도록 하고 6–10초 카드에서 12분을 1분으로 축약하지 않음. 피부 효과의 전후 차이를 보여주지 않으며 ‘무자극·리프팅·시술 대체’ 표현을 넣지 않음. 5단계 경쟁사 대조 뒤 후킹·색감·키워드를 수정할 수 있고, Higgsfield/Kling/CapCut용 장면별 프롬프트는 6단계에서 확정함.

## 12. 메시지의 세 가지 소스와 채택 근거

### 공식몰: 제품이 설명하는 가치와 사용 조건

[공식몰 키워드 대장](../analysis/task2/glow_product_verification.md)에 O01–O12의 원문 표현·상품 요약/이미지 위치·보존 파일·채택 판단을 기록함. 공식 상세 이미지를 추가 확인해 물방울 초음파, 3중 주파수, 광채, 촉촉함, 물방울 헤드, 12분, 준비물 등을 분리함. 상세페이지의 브랜드 주장을 독립 검증된 효능으로 표시하지 않음. 권위·최상급·가격 소구도 수집하되 이번 주 후킹에는 채택하지 않음.

### 콘티와 제작 프롬프트로 넘기는 방식

1. O03 + R01·R02 → 0–3초의 촉촉함·피부결 고민. R06에 따라 개선 보장·피부 전후를 제외함.
2. O02·O06 → 3–6초의 제품명·기술 카드. 기술과 효익을 연결하되 전문기관 동등성·침투 애니메이션은 제외함.
3. O10·O11 + R05 → 6–13초의 12분·준비물 안내. 15초 영상 안에 사용이 끝나는 연출을 제외함.
4. B01–B03에서 제안한 고민→제품 이유→랜딩의 연결 구조 → 13–15초 CTA와 랜딩 상단의 정보 순서를 맞춤. 성과가 입증된 구조라는 표시는 하지 않음.
5. 5단계 원소재 대조 후 키워드·문체·장면을 확정하고, 6단계 프롬프트에 컷 목적·O/R/B 근거 ID·표현할 정보·금지 표현·일관성 기준을 넣음.

현재 주편의 메시지는 **촉촉함·피부결이라는 관리 고민 → 3중 주파수 물방울 초음파라는 제품 설명 → 실제 시간·준비물 확인**임. 브랜드의 소구와 소비자 언어가 만나는지를 보여주는 콘텐츠 기획안이며 제품 효과나 메시지 성과를 입증한 결론이 아님. 현 자료로는 A/B 결과를 만들 수 없으므로 포트폴리오에는 실제 수집·분석·제작·검수 범위만 성과로 기록함.
