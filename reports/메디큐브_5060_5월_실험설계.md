# 메디큐브 5060 · 5월 메시지 실험 설계안

상태: 포트폴리오용 **사전 설계안**. 실제 집행·성과 자료는 없음. 대상 연도와 집행 일정은 확정 전.

## 1. 관찰에서 실험 질문으로

2026년 5월 4일 주 5060 브랜드 검색과 이미용가전 클릭 파일의 일부 지표가 전주보다 올랐다. 같은 기간 여러 출시·행사가 겹쳤으므로 **5월이라는 시점이 상승의 원인이라고 판정할 수 없다**. 또 5060 이미용가전 클릭 파일에서는 5개 키워드 중 3개의 값이 0 또는 매우 낮다. 74.3%는 선택 키워드 안의 상대 비중이며 실제 구매율이나 시장 점유율이 아니다.

실험 질문: **5월에 50대 이상에게 부스터 프로 X2 광고를 보여 줄 때, ‘선물과 사용 편의’ 메시지가 ‘제품 기능’ 메시지보다 상품 페이지 방문을 늘리는가?** 이 실험은 메시지 효과를 판정한다. 5월 자체의 효과는 별도 비교가 필요하다.

## 2. 사전 등록할 A/B 설계

| 항목 | 사전 결정안 |
|---|---|
| 모집단 | 국내 50세 이상 광고 도달 가능 이용자. 실제 구매자 연령과 다를 수 있으므로 자사몰 주문 연령을 별도로 확인 |
| 무작위 배정 | 광고 플랫폼의 분할 실험으로 이용자 단위 1:1 배정. 두 군의 노출 중복을 차단하고 같은 기간 운영 |
| A | 제품 기능 중심 제목과 본문 |
| B | 선물·간단한 사용법 중심 제목과 본문 |
| 동일하게 유지 | 제품, 가격, 혜택, 이미지·영상 구성, 랜딩 페이지, 예산·입찰, 게재 위치, 빈도 제한, 운영 기간 |
| 1차 지표 | 배정 이용자당 **상품 페이지 방문 여부**. 분모는 배정된 이용자, 분자는 해당 이용자의 랜딩 페이지 방문 이벤트가 1회 이상 확인된 수 |
| 보조 지표 | 클릭률, 장바구니 진입률, 50세 이상 신규 구매율, 광고비 대비 매출. 보조 지표는 탐색용 |
| 안전 지표 | 페이지 오류율, 이벤트 누락률, 광고 부정 반응, 환불률 |
| 관찰 기간 | 집행 기간과 구매 관찰 기간을 분리. 방문은 노출 뒤 24시간, 구매는 노출 뒤 7일을 가안으로 두고 실제 구매 지연 분포 확인 후 사전 확정 |
| 판정 | 양측 검정, 유의수준 5%, 검정력 80%를 가안으로 둠. 1차 지표의 군 간 차이와 신뢰구간을 보고하며, 표본이 차기 전 조기 종료하지 않음 |

**집행 전 빈칸**: 기준 방문율, 실무적으로 의미 있는 최소 개선 폭(MDE), 주간 50세 이상 도달 규모, 구매 지연 분포, 개인정보 동의 및 연령 필드 가용성. 이 값으로 군별 필요 표본과 운영 기간을 계산해야 한다. 현재 공개 자료로 표본 수·기간·예상 매출을 숫자로 확정할 수 없다.

## 3. 계측·품질 점검

1. 광고 노출·클릭, 랜딩 방문, 장바구니, 주문 이벤트의 이용자 식별자를 연결하고 중복 이벤트를 제거한다. **왜 필요한가:** 공개 클릭 비중처럼 분모가 흔들리면 실험 효과도 해석할 수 없다.
2. 집행 전 두 군의 배정 비율, 연령·기기·게재 위치 분포, 이벤트 누락률을 점검한다. 1:1 배정이 크게 어긋나거나 한 군의 랜딩 오류가 높으면 분석을 보류한다.
3. 동일 이용자의 교차 노출과 할인·재고·방송 편성 변경을 기록한다. 변경이 생기면 사전 등록한 중단·재실험 규칙을 적용한다.
4. 1차 지표는 배정 기준으로 분석한다. 클릭한 사람만 남겨 비교하면 광고가 클릭을 유도한 효과와 클릭 이후의 행동이 섞인다.

## 4. 5월 ‘시즌 효과’ 검증은 별도 질문

A/B 두 군은 모두 5월에 노출되므로 위 실험으로 **5월이 다른 달보다 효과적인지** 알 수 없다. 가능하면 2027년 5월 전후의 동일 요일·프로모션 조건을 맞춘 주와 전년도 같은 주를 비교하고, 30·40대도 비교군으로 함께 본다. 가격·광고비·재고·홈쇼핑 방송·경쟁 행사 변동을 기록한다. 이 비교는 관찰 연구여서 시즌의 인과 효과를 확정하지 못한다. 반복 연도와 실제 구매 자료가 쌓이면 설계를 보강한다.

## 5. 결과 해석과 포트폴리오 표기

| 결과 | 허용되는 해석 |
|---|---|
| B의 1차 지표 개선이 사전 MDE 이상이고 신뢰구간도 0을 넘음 | 해당 집행 조건에서 선물·사용 편의 메시지가 상품 페이지 방문을 늘렸다는 근거 |
| 차이가 불명확하거나 표본 부족 | 우열 미판정. 효과가 없다는 증거로 단정하지 않음 |
| 방문은 늘고 구매는 불명확 | 메시지가 탐색을 늘렸을 가능성. 구매 효과는 별도 검증 |
| 5월 관찰 비교에서도 상승 | 시즌 가설을 보강하는 신호. 행사·채널 영향이 남아 있으므로 인과 확정 금지 |

포트폴리오에는 **문제 정의 → 공개 자료의 한계 확인 → 가설 → 무작위 실험 설계 → 계측·판정 규칙**의 순서로 제시한다. 실제 집행 전에는 ‘실험 결과’라는 제목을 쓰지 않는다. 면접에서는 74.3%의 분모 문제를 발견하고 공개 지표를 실제 구매 성과의 대용으로 사용하지 않은 판단을 설명할 수 있다.
