# 5060 홈쇼핑 상품·방송 확인과 정적 콘텐츠 표현 검토

> 조사일: 2026-11-21. 1장의 15초 영상안 검수는 과거 기획의 기록이다. 현행 5060 산출물은 GS샵 X2 연계 포스터·정적 정보 카드·프로모션 기획서다. 공개 페이지의 상품 노출·방송 이력과 실제 5060 구매 이력은 구분한다.

## 3. ‘어디서 무엇을 샀는가’로 가는 자료 경로

1. **공개 편성 대장**: 방송사, TV/데이터방송/모바일 라이브/온라인몰 구분, 방송 날짜·시각, 프로그램 ID, 상품 페이지 ID, 실제 구성품·옵션, 표시광고주체, 가격·혜택, 근거 URL·확인 시각을 행 단위로 저장한다. 상품 페이지의 변동값은 캡처일을 함께 적는다.
2. **방송사·자사 주문 대장**: 방송 ID와 실제 주문 SKU를 연결해 주문 방식(전화·웹·앱), 주문·취소·반품, 순매출, 비식별 고객 ID, 동의된 연령대(50대·60대 이상·미상), 신규 고객 여부, 수수료·송출비를 요청한다. 방송 연계 SKU와 일반 온라인몰 주문을 섞지 않는다.
3. **판정**: 채널별 연령 식별률을 먼저 보고, 방송별 50대·60대 이상 신규 순주문과 순매출을 별도 집계한다. 같은 제품의 자사몰·라이브와 비교할 때 가격·혜택·재고·노출 차이를 병기한다. 전용 코드가 없는 전화 주문과 연령 미상 주문을 숨기지 않는다. 방송 후 주문 증가만으로 인과 효과를 확정하지 않는다.

현재 접근 가능한 것은 1번의 일부뿐이다. 공개 판매·방송 화면에는 고객별 구매 이력이 없으므로 2번과 3번의 결과를 임의로 채울 수 없다. 내부 자료를 얻지 못하면 포트폴리오는 **채널·상품 검증 대장, 데이터 요청 명세, 판정 규칙, 조건부 포스터·정보 카드·프로모션 기획서**를 제시한다.

## 7. 채널·제품·연령의 조건부 연결 판정

**채택 가능한 기획 가설:** “5060의 디바이스 구매 검토를 돕는 GS샵 TV 연계 X2 사용 안내 콘텐츠를 기획한다.” GS샵의 2026-05-09 X2 론칭과 전체 메디큐브 디바이스 주문 이력은 **채널과 제품을 함께 검토할 이유**다. 같은 주 5060 부스터 프로 검색·메디큐브 이미용가전 클릭 상승은 **연령층의 탐색 단서**다. 세 자료의 관측 단위가 각각 방송 편성, 채널 전체 주문액, 검색·클릭이므로 이를 결합해 “5060 X2 구매 수요가 확인됐다”라고 말할 수는 없다. [TV홈쇼핑협회 현황을 전한 보도](https://nwww.newsis.com/view/NISX20260706_0003697419)의 60대 여성 구매 비중도 업계 전체 값이며 X2 구매자 구성은 아니다.

GS를 우선 선택한 이유는 **자료와 정적 기획을 연결하기 쉬운 채널**이기 때문이며 CJ·롯데보다 5060 매출이 높다는 비교 판정은 아니다. 정적 시안의 최종 카피·레이아웃은 경쟁사 정적 소재와 다시 대조한다.
