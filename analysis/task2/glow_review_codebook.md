# 글로우 리뷰 코드북 v1.1

## 분석 단위와 판정

공식몰 217행, 글로우픽 15행을 AI가 전수 읽고 1차 판정한 뒤, 같은 AI가 전략 핵심 코드와 경계 사례를 재검토함. 사람 또는 다른 분석자의 독립 재코딩은 미실시함. 출처별 분모를 유지하며 복수 코드를 허용함. 코드 없음은 관련 주제가 없거나 구체적 경험을 판정할 수 없다는 뜻이지 불만 없음이 아님. 아래 빈도는 잠정 코딩 결과임.

공식몰의 마스킹된 표현은 복원하지 않음. 작성자가 주장한 작용 원리·사용 시간·사용법은 공식 사실로 바꾸지 않음. 날짜·연령·제품 제공 플래그는 수집 표를 유지함. 본문 연령·직업만으로 페르소나를 확정하지 않음.

## 검토용 상태

- `explicit_nonuse`: 사용 전·아직 사용 못함을 명시한 공식몰 4365284, 4126470, 4114577. 효과 경험 코드 제외. 기대·배송·신뢰는 원문으로 보존함.
- `gift_recipient_report`: 공식몰 4126138, 4120105, 4111075. 선물 수령자 경험·미사용을 구매자 본인 사용과 구분함.
- 제품 제공 명시 5건은 제외한 민감도 집계도 병기함. 그 외 리뷰를 비협찬 또는 자비 구매로 확정하지 않음.
- 긍정·부정 코드가 한 리뷰에 함께 붙을 수 있음. 평점은 코드 판정의 대리변수로 사용하지 않음.

## 재현과 근거 확인

v1.1 재검토에서는 글로우픽 전체 15건과 공식몰의 HOME·PRICE_BARRIER·FIRST_DEVICE 해당 행을 다시 읽고, 전략에 인용한 근거와 대조함. 그 과정에서 확인한 누락을 포함해 11개 코드 부착을 수정했으며 해당 행의 `review_notes`에 이유를 남김. 새로운 독립 검증이나 전수 재코딩 완료를 뜻하지 않음.

`glow_review_annotations.json`은 리뷰 ID 또는 수집 때 만든 내부 식별키를 기준으로 수동 판단을 저장함. `code_glow_reviews.py`는 원문·코드를 결합하고 누락·중복·근거 불일치를 검사함. 코드별 근거는 해당 리뷰의 원문 전체를 보존해 문맥을 확인하도록 함. 짧은 전략 인용문은 전략 연결 문서에 별도로 제시함. 원문 전체를 근거로 보존한 행은 모든 문장이 그 코드를 지지한다는 뜻이 아님.

집계 명령: `python3 analysis/task2/code_glow_reviews.py`. 코딩 변경 시 JSON을 먼저 수정하고 재실행함. 독립 검토자는 원문과 코드를 대조해 불일치를 조정해야 하며, 현재는 독립 검증 완료로 표시하지 않음.
