## 추출 경로

브라우저 프레임 `#review_widget3_0` 안의 `.review_wrapper_info`를 행으로 읽음. `review_id`·`item_id` 속성을 보존하고 `.sf_review_user_score_avg`, `.sf_review_user_writer_name`, `.sf_review_user_write_date`, `.sf_review_user_write_review`에서 평점·표시명·날짜·본문을 추출함. `.sf_review_selected_warp`의 항목명과 값을 JSON으로 보존함. 따라서 CSV와 원본 HTML을 ID로 다시 대조할 수 있음.
