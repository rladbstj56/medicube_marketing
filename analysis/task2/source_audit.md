# Task 2 원자료 품질 감사

기준일: 2026-11-20. 감사 범위는 저장소의 5060 이미용가전 클릭 CSV, 기기 검색 XLSX의 조회 조건, 공식몰·글로우픽 리뷰 CSV다. 독립 재계산 결과는 [source_audit.json](source_audit.json)에 저장한다.

## 1. 5060 클릭 파일: 계산은 재현, 영값의 원인은 미확인

| 항목 | 확인 결과 |
|---|---|
| CSV 조회 조건 | 디지털/가전 > 이미용가전, 여성 50대·60대이상, 기기 전체 |
| 기간 | 전 키워드 0인 2025-11-01 부분주 제외, 2025-11-03–2026-10-26 완전주 52개 |
| 52주 중 0인 주 | 메디큐브 0주, 듀얼소닉 0주, 센텔리안24 37주, 프라엘 8주, 마미케어 52주 |
| 52주 최고 지수 | 메디큐브 100, 듀얼소닉 73, 센텔리안24 3, 프라엘 10, 마미케어 0 |
| 최근 13주 메디큐브 비중 | 주별 5개 키워드 내 비중의 단순 평균 **74.297% → 74.3%** |
| 산식 민감도 | 최근 13주 지수 합계의 비율 74.661%; 메디큐브·듀얼소닉만 남긴 주별 비중 평균 75.661% |

기존 74.3%의 **산식은 맞다**. 다만 클릭의 5개 키워드 중 하나는 전 기간 0이고 둘은 낮게 포착된다. 이 값만으로 카테고리 분류 오류인지, 키워드 문제인지, 실제 클릭 부재인지 결정할 수 없다. 숫자 0을 결측값으로 바꾸거나 임의로 채우지 않는다. 선택 키워드의 집계 범위 밖 클릭·주문 규모도 알 수 없다.

기기 검색 XLSX는 데이터랩 **통합검색**이며 여성 50–60대, 54주다. 키워드는 `메디큐브 에이지알·듀얼소닉·마데카 프라임·LG 프라엘·마미케어`다. 클릭 CSV는 **이미용가전 카테고리**의 52주이며 `메디큐브·듀얼소닉·센텔리안24·프라엘·마미케어`다. 제품명과 브랜드명이 섞이고 비교군도 다르므로 **검색 5.6%와 클릭 74.3%를 차감한 68.7p.p.는 해석 가능한 퍼널 지표가 아니다**. 계산 JSON과 차트의 해당 차감 표기를 제거했다.

**추가 확인에 필요한 것**: 동일 카테고리·동일 키워드·동일 52주로 다시 조회한 검색·클릭 자료, 키워드별 카테고리 포함 규칙 또는 실제 노출·클릭 로그, 50대와 60대의 개별 분해값. 공개 CSV만으로 영값의 원인은 확정할 수 없다.

## 2. 리뷰: 분모와 코딩 재현성

| 항목 | 확인 결과 |
|---|---|
| 공식몰 | 200행·고유 리뷰 ID 200개; 작성일 2024-11-18–2026-10-18. 전체 1,444건 중 200건의 추출 기준은 기록되지 않음 |
| 공식몰 `coded_axes` | 휴대 115건(57.5%), 입문·가성비 101건(50.5%). **태그 부착 비율**이지 의미 검증을 마친 언급률은 아님 |
| 공식몰 태그 대조 | `입문·가성비` 태그가 붙은 101건 중 고정 시드 `20261120`으로 뽑은 20건의 본문 앞부분을 살피고, 그중 ID 3882609·3881703·3881885·3874410의 전체 원문을 확인함. 이 4건에서는 첫 디바이스 사용·입문 또는 가격·가성비 언급을 확인하지 못함. 확인된 불일치 사례이며 전체 오류율 추정은 하지 않음 |
| 글로우픽 | 리뷰 82행 중 20·30대 연령 표기 74행(90.2%). 작성자 표시명 78개 중 20·30대 표시명 70개(89.7%) |
| 글로우픽 주제별 코딩 | 현재 CSV에 리뷰별 주제 태그 컬럼이 없어 기존 45건·30건 등의 수치를 재집계할 수 없음 |

글로우픽에서 같은 표시명이 미니와 미니 플러스에 각각 리뷰를 남긴 경우가 4개 있다. **90.2%는 리뷰 행 기준**이며 82명의 서로 다른 고객을 뜻하지 않는다. 표시명 78개도 계정 또는 구매자 고유 ID가 아니므로 고객 수로 단정하지 않는다. 공식몰과 글로우픽은 제품 구성·기간·연령 필터가 달라 두 표본의 언급률 차이를 플랫폼 효과로 해석하지 않는다.

**추가 확인에 필요한 것**: 공식몰 API의 200건 추출·정렬 규칙, 주제별 포함·제외 예시가 담긴 코드북, 리뷰 ID별 태그와 원문을 연결한 코딩표, 독립 재코딩과 불일치 조정 기록. 이 절차 전에는 주제별 비율을 카피의 확정 근거로 쓰지 않는다.

## 3. 재현 명령과 판정 범위

저장소 루트에서 아래 명령을 순서대로 실행한다. `openpyxl`은 계산 스크립트에 필요하며, 독립 검증 스크립트는 XLSX를 ZIP/XML로 별도 파싱한다.

```bash
python3 analysis/task2/audit_sources.py
python3 analysis/task2/calc2.py
python3 analysis/task2/calc3.py
python3 analysis/task2/verify2.py --numeric-only
```

현재 결과: 원자료 독립 재계산 **162항목, 불일치 0건**. 이는 계산과 파일 범위가 재현된다는 뜻이며 리뷰 코딩의 의미 적합성, 클릭 영값의 원인, 시즌 효과, 구매 전환은 검증하지 않는다. Task 2 PDF는 이전 판본이고 MD와 일치하지 않는다. PDF 빌드 경로·렌더 의존성은 별도 복구 대상이므로 현 단계에서 PDF 일치 검증을 완료했다고 표시하지 않는다.
