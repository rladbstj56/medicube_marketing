## 2. 수집 방법 (재현 절차)

1. 상품 페이지의 리뷰 영역은 JS 컴포넌트로 렌더링된다. 페이지 스크립트(`getItems_ui.js`)의 리뷰 호출부에서 공개 JSON 엔드포인트를 확인했다.
   - 목록 최초 호출: `GET https://m.gsshop.com/product/api/revw/v0/reviewMain/{prdid}?mseq=397078&prsnInclYn=Y&prsnFilterYn=N`
   - 이어보기(20개 더보기): `GET https://m.gsshop.com/product/api/revw/v0/reviewPage/{prdid}?listing={정렬}&prdClsCd={상품분류}&bestreviewscore=…&messageId=…&satisfact=…&participantCnt=…&contentsFlag=…&titleFlag=…&prsnInclYn=Y`
2. 응답은 **20건 + 커서 1건(21건)** 구조다. 마지막 1건은 다음 페이지 요청용 커서이며, 다음 응답은 그 커서 1건을 다시 머리에 붙여 내려준다. 수집기는 `items[:-1] + new`로 커서를 교체해 중복을 막고, 신규가 1건뿐인 응답을 마지막 페이지로 판정한다.
3. **단일 정렬로는 221건이 채워지지 않는다.** 커서 정렬값(추천점수)이 같은 리뷰가 섞이며 중복·누락이 생긴다. 정렬 5종을 각각 끝까지 수집한 뒤 `prdrevwId` 기준 합집합을 만들어 221건을 확보했다.

## 3. 중요 발견: 리뷰는 상품군 단위로 공유된다

- 화이트 상품 페이지의 183건은 **핑크 페이지 221건의 부분집합**이다(중복 183, 화이트 단독 신규 0).
- 두 페이지의 차이 38건은 SKU `메디큐브부스터프로X2핑크+글루타치온앰플1+PDRN세럼10ml` 리뷰와 정확히 일치한다.
- 리뷰 레코드의 `prdCd`는 221건 모두 조회한 페이지의 상품번호(1117330943)로 내려오므로, **리뷰별 실제 구매 SKU는 `exposPrdNm`(리뷰에 표시되는 구매 상품명)으로만 구분할 수 있다.**
- 따라서 "핑크 221 + 화이트 183 = 404"로 더하면 **중복 집계**다. X2 리뷰 모집단은 **221건(중복 제거)** 으로 본다.

## 6. 한계와 해석 주의

- **연령 정보 없음**: GS샵 리뷰에는 작성자 연령·성별이 표시되지 않는다. 따라서 이 데이터는 '5060 리뷰'가 아니라 **'GS샵 X2 구매자 리뷰'** 이다. 본문에서 연령대를 스스로 밝힌 리뷰는 3건(1.4%)뿐이며, 이는 **자발적 언급 건수**일 뿐 구매자 연령 분포가 아니다.
- **표본 규모와 시점**: 2026-05-10~2026-11-10, 221건. 월별로 5월 87건(39%)·6월 57건·7월 31건·8월 25건·9월 9건·10월 9건·11월 3건으로 **런칭 직후에 집중**되어 있어, 장기 사용 후기 비중이 낮다.
- **구매자 848명 대비 221건(약 26%)** 의 작성률이며, 리뷰는 자발적 작성자 표본이다(리뷰 리워드 제도 운영: 페이지에 리뷰 50원·사진 50원 적립 안내).
- **한달 사용 리뷰 75건(33.9%)** 은 플랫폼 분류이며, 작성 조건(이벤트·리워드)은 확인하지 못했다.
- **'앰플 순서 혼란'은 미확인**: 계획 단계에서 함께 보려던 앰플 순서·사용 순서 혼란은 이 221건에서 확인되지 않았다. 코드 B6에 든 사례는 모두 설명서·가독성·첫 사용 관련이며, 앰플 사용법 문의는 이 상품의 상품문의 영역으로 추정된다.
- **효능 근거가 아니다**: 리뷰는 개인의 체감 진술이며, 전후 비교·측정값이 없다. 콘텐츠에서 효능·개선 효과의 근거로 인용할 수 없다.
- **채널 한정**: GS샵 단일 채널 리뷰다. 공식몰·뷰티 커머스 리뷰와 모집단이 다르다.
- **색상 구분의 한계**: `color`는 상품명 문자열에서 파생한 값이다. 패키지 상품명에 색상이 없는 19건은 '미상'이며, 리뷰 내용만으로 색상을 확정할 수 없다.
