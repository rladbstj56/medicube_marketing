## 제작 가능성과 남은 조건

- **지금 설계 가능한 형식**: 제품명을 표시한 타이포그래피, 자체 제작 세면대·스킨케어 준비 장면, 시간·준비물 안내 카드. 공식 모델 영상이나 제품 사진을 복제하지 않아도 15초 구조를 구현할 수 있음.
- **제작 단계 확인**: 공식 이미지·영상의 공개 광고 재사용 권한은 아직 확인하지 않았음. 원문 열람·분석용 보존과 광고 소재 사용을 구분함. 제품 이미지가 필요하면 권한이 확인된 소재를 확보한 뒤 확정함.
- **제외할 장면**: 근거 없는 피부 전후, 침투 깊이 애니메이션, 시술 대체, 무자극 보장, 실제 사용 없이 만든 사용자 후기, 검수하지 않은 얼굴 접촉·금지 부위 시연.
- **판정 범위**: 현재 비시연형 정보 콘텐츠는 설계 가능함. 모든 모드별 사용법·금지 부위·주의사항의 전수 검증 완료로 표시하지 않음. 추가 사용 시연은 해당 장면 검수 후에만 제작함.
